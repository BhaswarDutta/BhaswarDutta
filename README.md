- After tailoring resumes for countless job applications myself, I created **Morpheus MD** to make the process faster and easier.

The motto is simple:
> If recruiters can use AI so can the applicants.

- **Tech Stack:**
	- **Frontend:** HTML, CSS, JS, HTMX
	- **Backend:** FastAPI, Pandoc, Google Gemini API
	- **Deployment:** 
		- Linux VPS running Ubuntu 24.04 LTS
		- Docker for containers
		- NGINX for Reverse Proxy
		- UFW for Firewall
		- Fail2Ban to prevent brute force attacks
		- Certbot for SSL Certificate
		- `uv` for python package management
		- `git` for pulling latest code to VPS

### 🪞 Aphrodite Frame
**This is how I got into Web Dev. A simple `streamlit` project**

_Make your images Instagram ready without cropping_

🔗 Live Demo: https://aphrodite-frame.streamlit.app/

💻 Source Code: https://github.com/BhaswarDutta/aphrodite_frame

![Python](https://img.shields.io/badge/Python-111111?style=for-the-badge&logo=python)
![Streamlit](https://img.shields.io/badge/Streamlit-111111?style=for-the-badge&logo=streamlit&logoColor=FF4B4B)
![Pillow](https://img.shields.io/badge/Pillow-111111?style=for-the-badge&logo=python&logoColor=3776AB)
![CSS3](https://img.shields.io/badge/CSS3-111111?style=for-the-badge&logo=css&logoColor=1572B6)

- Add white borders to your images to fit Instagram's strict aspect ratio
- Thus you don't have to crop your image to post
- Options between the two aspect ratios:
	- 1:1 (Square)
	- 4:5 (Portrait)

- **Tech Stack:**
	- **Frontend:** Python with Streamlit, Custom CSS Injection in Streamlit using markdown
	- **Backend:** Python with Pillow for image processing
	- **Deployment:** 
		- Currently deployed on the free Streamlit Community Cloud
		- I have later plans to Dockerize it and bring it on my VPS
